## 插图复现

在专栏根目录执行：

```bash
node 15-配套代码/render_figures.mjs /tmp/llmgw-ch15-preview
```

依赖 Node.js、`sharp`、`@napi-rs/canvas` 和中文字体。默认使用 Hiragino Sans GB，可通过 `DIAGRAM_FONT` 指定其他已安装字体。模块可从正常 Node 模块路径加载，也可用 `DIAGRAM_NODE_MODULES` 指定已安装依赖目录。更换字体后需重新检查文字宽度和布局。

正式 PNG 写入 `配图`，可编辑 SVG 写入 `配图/源文件`；彩色 / 灰度预览及文字、节点、连线的几何数据写入指定预览目录。前缀边界与括线是辅助标记，与流程连接线分别处理。

## 图示边界

图 15-1 的向量检索只负责候选发现，复用条件还包括实体、时间、数据版本、上下文、输出约定及当前权限。不通过或无法确认适用性时按未命中处理，后续调用仍需当前授权、预算和资源准入；鉴权失败不能通过回源绕过。

图 15-2 按模型实际处理顺序作抽象示意，框内文字表示内容类别，块宽不对应 Token 数。共同前缀从起点连续匹配，不能跳过不同部分直接复用后面的相同材料。图中长度不是厂商缓存门槛，匹配范围也不保证实际物理命中；重新组织输入不能改变角色、优先级或业务语义。

图 15-3 展示缓存控制流程，不表示必须等响应完整缓存后才交付。实时输出可以边生成边转发，普通结果缓存写入必须等到完整性及业务校验完成；不适合缓存的请求即使正常生成成功，也不能因此自动获得写入资格。精确与语义缓存分别决定是否收录。工具调用执行、服务端状态和签名句柄等需要专用策略，不能按普通结果重放。
