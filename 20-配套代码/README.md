# 第 20 讲：Prompt 注入与数据脱敏

本目录包含一个受限的可逆替换示例、离线演示、回归测试，以及三张图的绘制源码。示例展示请求作用域、恢复许可和流式状态，不提供完整的 PII / 密钥检测器、鉴权服务、内容护栏或生产网关。

## 运行离线示例

仅依赖 Python 标准库，在本目录执行：

```bash
python3 -B demo.py
python3 -B -m unittest -v test_pseudonymizer
```

演示使用教学身份、手机号与 `example.com` 邮箱，不调用模型和审核 API。随机请求标识每次运行不同；还原后的演示文本为：

```text
您好！我们将通过 13812345678 与您联系，回访结果发送到 zhang@example.com。
```

示例打印的是合成数据，生产代码不应照搬这些原文输出或记录映射。回归测试共 18 项，另含占位符多个切分点的子用例。

## 组件契约

- `Scope` 绑定租户、请求和最终接收者，必须来自可信应用的鉴权上下文。它不是身份凭证，不验证客户端自报身份。
- `mask()` 仅接受一次输入。它在原文上收集 EMAIL、IDCARD、PHONE 的候选区间，优先较长实体，再按确定的识别器优先级解决重叠，最后统一替换。相同类型和值复用当前实例的同一标记。
- 占位符带有 96 位随机请求标识，用于降低碰撞和跨实例复用风险，不是访问授权凭证。输入中的 `⟦`、`⟧` 为保留字符，本例直接拒绝；生产环境如需支持这些普通字符，应设计独立的转义层。
- `RestoreGrant` 由可信应用在完成授权后生成，指定同一作用域、明确的交付通道和允许恢复的具体标记。客户端或模型不能直接决定这些字段。示例不实现业务权限查询、许可吊销、TTL、版本持久化或签名令牌。
- 只允许 `trusted_plain_text` 通道。接收端必须字面展示，不解析 HTML / Markdown，不自动加载 URL；标记的样式或通道名称本身无法约束错误配置的渲染器。恢复器不是 HTML 清洗器，测试特意保留这个边界。URL、工具参数等通道直接拒绝，需要由相应执行层另行设计结构化填充、授权与最终参数校验。
- 每个实例只创建一个输出字段恢复器。`feed()` 接收已经解码、解析协议后的字符串，不能直接传入 SSE 字节或完整 JSON。未知、改写、跨作用域、未获准或超限的内容会终止该字段；不会模糊匹配恢复原值。
- 暂存始终是当前已知标记的有效前缀，长度受标记本身约束。`finish()` 遇到未闭合标记报错，不刷新残留片段；`abort()` 丢弃暂存。已返回的前缀无法撤回，调用方要遵守第 19 讲的放行与协议中断规则。
- `close()` / `with` 释放本对象持有的映射与暂存引用，禁止复用。它不是安全内存擦除，也不会清除调用者保存的原文、已经返回的字符串、转储或交换空间。

默认限制按 Python 字符数计：输入 32768、选中实体区间 256、累计流式输入 65536、实际恢复后输出 65536。候选匹配数量另有限制，超限报错而非截断。部署仍需在字节层限制请求体、设置总时限与全局并发，不能把单实例上限当作服务容量治理。

三个识别器只是格式示例：不实现身份证校验位或完整邮箱标准，不覆盖国际号码、所有 Unicode 形式、中文实体、附件与密钥。检测失败可能留下原文，不能把示例用于真实敏感数据保护。原值授权、输入与输出内容审查、前端渲染契约均是调用方责任。

## 回归覆盖

18 项测试涵盖：重复值一致替换、手机号与邮箱的重叠、邮箱后标点、占位符所有两块切分位置及逐字符输入、输入标记碰撞、租户 / 请求 / 接收者隔离、禁止恢复到 URL / Markdown / HTML / 工具参数、字段级许可、跨实例标记、异常尾段、非法长前缀、累计输出与恢复膨胀上限、输入与实体数量上限、清理及关闭后复用，以及纯文本契约不等于标记语言清洗。

这些测试证明的是受限组件的行为，没有评估模型注入防护效果、PII 检测召回率、真实客户端渲染、生产权限系统或系统吞吐。
