# 第 13 讲：重试、熔断与 Fallback

本目录保存第 13 讲的教学伪配置和配图源代码，不包含可运行的容错引擎。

## 文件

- `resilience-example.yaml`：与正文 YAML 片段一致的策略示意。字段不属于 LiteLLM 或其他产品，不能直接加载到网关。
- `render_figures.mjs`：生成三张可编辑 SVG、300 dpi PNG，以及用于检查的彩色 / 灰度预览和几何数据。

## 伪配置的阅读方式

示例把执行资格、尝试预算、故障范围、探测和候选目标放在同一份策略中，展示它们需要共同生效。20 秒、3 次、50% 等均为教学数值，不是生产推荐值。

- 首次调用、重试与 Fallback 共用每请求尝试数和总截止时间；每次派发重新检查资源额度。
- 额外尝试预算以同一租户与业务入口最近 60 秒的首次上游调用数为分母，重试和 Fallback 共用 10% 的额度。本例没有低流量启动额度，首次调用很少时可能不允许额外尝试。
- 禁止条件优先。错误属于可恢复类别，不代表已经通过重放、交付、目标兼容性和预算检查。
- 有效 `Retry-After` 是其适用范围内的最短等待；剩余时间不足时停止，不截短提示后提前请求。
- 半开探测并发是同一熔断范围内的总上限。跨实例协调、恢复轮次、结果归因和逐步放量仍需实现。
- 候选名称只是占位符；实际能力、状态、索引兼容性和调用权限需要另行核实。本例不允许改变原输出契约。

正文中的失败路径表是上线前建议执行的验收清单，不代表已经完成相应的故障注入或分布式测试。

## 插图复现

在专栏根目录执行：

```bash
node 13-配套代码/render_figures.mjs /tmp/llmgw-ch13-preview
```

依赖 Node.js、`sharp`、`@napi-rs/canvas` 和中文字体，默认使用 Hiragino Sans GB。依赖可从正常 Node 模块路径加载，也可用 `DIAGRAM_NODE_MODULES` 指定已安装依赖目录；`DIAGRAM_FONT` 可指定另一款已安装的中文字体。更换字体后需要重新检查布局。

正式 SVG 写入 `配图/源文件`，PNG 写入 `配图`；预览与文字、节点、连线几何数据写入命令指定的目录。图稿参考宽度 150 mm、最小文字约 9.1 pt，PNG 宽 1772 像素、密度 300 dpi。SVG 保留可编辑文字，不依赖外部图片。

| 图号 | 文件名 | 本轮处理 |
| --- | --- | --- |
| 13-1 | `13-重试风暴` | 保留原节位置并重绘，明确九次是附带条件的尝试数上限 |
| 13-2 | `13-熔断状态与恢复` | 新增，分开布置成功恢复与探测失败的回路线 |
| 13-3 | `13-Fallback资格与停止条件` | 新增，展示执行资格、目标资格、预算与停止路径 |
