# 第 21 讲：合规能力与配图

本目录保存三张插图的绘图源码和复现说明。正文中的日志留存、删除、数据出境、内容标识与服务准入是工程设计说明，没有提供可部署的合规判定引擎、法律认证或生产配置。

## 插图复现

在专栏根目录执行：

```bash
node 21-配套代码/render_figures.mjs /tmp/llmgw-ch21-preview
```

依赖 Node.js、`sharp`、`@napi-rs/canvas` 和中文字体。默认字体为 Hiragino Sans GB，可通过 `DIAGRAM_FONT` 指定其他已安装字体；模块可从正常 Node 模块路径加载，也可通过 `DIAGRAM_NODE_MODULES` 指定已安装依赖目录。更换字体后需重新检查文字宽度和布局。

正式 PNG 写入 `配图`，可编辑 SVG 写入 `配图/源文件`；指定预览目录保存彩色、灰度预览及文字、节点、连线几何数据。绘图过程不连接模型、日志平台、身份服务或监管系统。

| 图号 | 文件名 | 内容与位置 |
| --- | --- | --- |
| 21-1 | `21-日志分层留存与删除` | 新增于日志一节，区分必要记录与获准内容、限制处理与副本清理 |
| 21-2 | `21-数据驻留与跨境访问` | 新增于数据驻留一节，展示境内推理之外的审核、观测、备份和境外查询路径 |

三图参考宽度均为 150 mm，最小文字约 9.1 pt；PNG 宽 1772 像素，密度 300 dpi。SVG 保留可编辑文字，不引用外部图片，不放公众号标识；灰度下仍可通过文字、位置和线条理解。具体日期、数量阈值与法定期限主要留在正文及核实记录中，避免图片成为简化的法律判定表。

## 图示适用边界

图 21-1 是按记录对象执行的生命周期示意。删除请求或到期后，分别判断哪些仍须保留、哪些可删除；限制处理分支以适用法律条件为前提，不表示企业可任意以技术困难延长保留。一个请求可能对应多种记录，具有不同期限。下方处置记录不复制被删除正文，限制处理状态及副本清理需继续跟踪。期限起算、行业规则、法定保存、具体删除方式均需按实际业务确定；图不承诺所有副本即时删除。

图 21-2 的位置仅作示例。生成模型在境内，审核、观测和备份可能在境外；境外运维双向箭头表示查询与数据返回。连线表示需要审查的潜在路径，不代表获准，也不要求所有系统采用这些外部组件。实际控制点可以位于应用、网关、代理、存储和身份系统。图不以供应商国籍或域名判断驻留，不声称网关日志能证明供应商内部的全部数据流动。

图 21-3 只画受控允许路径，未逐一画出拒绝、取消、重试和投诉支线；这些操作也受实际策略约束。输出审核的阻断与缓冲方式承接第 19 讲，不暗示所有内容在生成或交付前已完成检查。上游能力、标识与用量取得依赖协议和服务支持；取消仍为尽力而为，未知用量不能填零。下方治理工作贯穿各阶段，不是请求结束后才启动。
